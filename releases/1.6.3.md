# LLM Workbench v1.6.3

## Overview

Two small changes after v1.6.2. The sidebar can now filter conversations by **pinned or not
pinned**, and the **Llama Dashboard shows only the cards it has data for**: off Linux, or
without an NVIDIA card, it is the server, model and speed cards and nothing else.

Five commits on `dev` since v1.6.2 (2026-11-21), 10 files, +180 / −17.

---

## 📌 Filter conversations by pinned

A pin button sits at the right end of the "Filter by title…" row in the sidebar. Each click
steps to the next state:

- **All** (dim outline pin): every conversation.
- **Pinned only** (filled amber pin).
- **Not pinned** (amber pin with a slash).

It combines with the color chips and the title box, and the choice is kept across reloads like
the color filter. When nothing matches, the list says so and offers a link to clear the
filter. Starting a new chat while "pinned only" is on switches back to All, so the new chat
stays in the list.

## 🖥 Llama Dashboard: no empty cards

v1.6.2 showed every card and explained the empty ones. Now a card with nothing to show is left
out.

- **Not Linux.** Nothing on the machine is probed, not even `nvidia-smi` on Windows. The
  dashboard shows Server, Model and Speed.
- **Linux without an NVIDIA reading.** No GPU card and no Stability card: an Xid is an
  NVIDIA-on-Linux log line.
- **llama-server on another machine.** The same three cards.
- **Updates** appears wherever a llama.cpp checkout is known: found from the running binary on
  Linux, or named by `LLAMA_CPP_DIR` in `.env` on any system.
- **One line under the cards** says what the full panel needs (Linux, an NVIDIA card,
  llama-server on the same machine), only when cards are missing.

On Linux with an NVIDIA card and a local server nothing changes: all seven cards are shown.
The README now says Linux with an NVIDIA card is recommended for the dashboard.
