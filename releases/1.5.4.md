# LLM Workbench v1.5.4

## Overview

Templates are reviewed by the LLM on save, their author notes live apart from the HTML, and a
review can no longer replace working JavaScript with code that does not parse. Plus a sidebar
title filter and a Yahoo Finance proxy for applets.

Six commits on `dev` since v1.5.3 (2026-11-06 and 2026-11-07), 18 files, +1,361 / −88.

---

## 📄 Templates

- **LLM review on save.** "Save as Template" stores the raw HTML at once and reviews it in the
  background: a deterministic audit (unresolved placeholders, hardcoded datasets, fetches with no
  catch, dates and values baked into the markup, no resize message) goes to the model with the HTML,
  and a guard decides whether the answer may replace the original. ⚡ runs it again on demand.
- **Author notes out of the HTML.** A template's leading `<!-- … -->` comment (which files to build,
  which symbols to fetch, what never to change) is now `tpl.notes`, shown to the model outside the
  code fence and never copied into the applet. The CHPY template's 1,761-char comment was being
  reproduced verbatim in every answer, and one stray `)` in a regex literal killed the script.
  Existing records migrate on first load; `template_save` writes the comment back into the file.
- **Notes as review context, contract audit.** The review sees the notes (context only) and the
  audit flags a noted data file the HTML never references, or a promised column it never mentions.
- **Parse guard.** Every inline `<script>` of a review answer is parsed (`vm.Script`, no
  execution); an answer that no longer parses is rejected and the `!` marker names the line. The
  review model wrote `/(…)$/;` as `/(…)$/);` twice in one day — the second time the guard held.
- `[template: …]` expansion inserts the HTML literally (`'$' + v` used to lose its dollar signs).

## 🔍 Sidebar title filter

A case-insensitive substring filter on conversation titles under the color chips; the two compose.
Escape or ✕ clears. Title-only: the list API carries no message text.

## 📈 `/api/yahoo`

GET-only proxy for Yahoo Finance's chart endpoint (symbol, range and interval whitelisted), since
applet iframes cannot reach it directly.

## ✅ Validation

`npm test`: 98/98 (70 at v1.5.3 + 28). No `.env` change, no extension change, no reload.
**Upgrade:** `git pull` → restart. Templates saved earlier are migrated on the first request.
