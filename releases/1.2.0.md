# LLM Workbench v1.2.0

## Overview

A UI release. The headline is a **sidebar color filter** — a tab-like chip strip above the conversation list that filters chats by session color, modeled on the section-tab pattern in note-taking apps. A purely additive, frontend-only change: two files touched (`src/public/js/app.js`, `src/views/index.html`), no server, route, or data-model changes.

> **Note on scope:** because `master` did not yet contain v1.1.0, the `dev → master` PR that ships this release also brings the entire **v1.1.0** feature set (Cite mode, the hotel `countryCode` fix, and the model-launch docs). See [`releases/1.1.0.md`](1.1.0.md) for those. This document covers only what is new **on top of** v1.1.0.

## 🎨 Sidebar Color Filter

Conversations already carry a session color (the strip on the left edge of each sidebar row). This release makes that color a **filter dimension**: a horizontal strip of chips sits above the conversation list, one per color in use, and clicking one narrows the list to conversations of that color.

### Behavior

- **Tab semantics, one active at a time.** An `All` chip plus one chip per color that actually has conversations. Clicking a color filters to it; clicking the **already-active** color chip clears back to `All` (one-click escape, tab-like feel) — `src/public/js/app.js:388`.
- **Self-hiding, always one row.** Ten session colors exist, but only colors with at least one conversation get a chip, and the whole strip hides when fewer than two colors are in play (`renderConvFilter`, `src/public/js/app.js:367`). In practice the strip stays a single row regardless of how many colors the palette defines.
- **Count badges.** Each chip shows its conversation count; the `All` chip shows the total. The count doubles as the affordance that makes the swatches read as interactive rather than decorative.
- **Active-state cue.** The active chip gets full opacity, a dark backing, and a **2px bottom border in its own session color** (the "attached tab" look). Inactive chips sit at 45% opacity and brighten on hover — `src/views/index.html:50`.
- **Keyboard accessible.** The strip is a `role="tablist"` with `role="tab"` chips, `aria-selected`, roving `tabindex`, and ←/→ arrow-key navigation (`src/public/js/app.js:415`).
- **Tooltips.** Each color chip reuses the existing `data-tip` CSS-tooltip mechanism to show that color's saved session-prompt title — the same text shown on the top-bar `+` buttons.

### Persistence & edge cases

- **Choice persists** in `localStorage` under `sidebarFilter` (default `'all'`), so it survives reload, browser restart, and machine shutdown — `src/public/js/app.js:20`.
- **Automatic fallback to `All`.** If the selected color has zero conversations at render time — e.g. its last conversation was deleted, or only unpinned conversations of that color existed and were lost on a server restart — the filter silently resets to `All` (`src/public/js/app.js:434`). A filter can only stay pinned to a color while a conversation of that color exists to anchor it.
- **New-chat safety.** Creating a chat in a color while a *different* color filter is active switches the filter to the new chat's color, so a freshly created conversation can never be created into invisibility — `src/public/js/app.js:2277`.
- **Empty-filtered state.** When a color filter matches nothing, the list shows `No <color> conversations.` with an inline **Show all** button rather than a blank pane — `src/public/js/app.js:445`.

### Wiring

- New state: `state.sidebarFilter` (persisted) and `state.sessionTitles` (color → saved-prompt title, populated in `refreshSessions`, `src/public/js/app.js:2927`) for chip tooltips.
- `SESSION_ORDER` (`src/public/js/app.js:25`) fixes chip order to match the top-bar session-button order.
- `renderSidebar` (`src/public/js/app.js:426`) now computes per-color counts first, applies the fallback, renders the chip strip, then renders only the visible (filtered) conversations. `setSidebarFilter` is the single mutation path that persists and re-renders.
- Markup: `#conv-filter` `role="tablist"` docked inside `<aside id="sidebar">`, above `#conversation-list`, `shrink-0` so it never scrolls with the list — `src/views/index.html:214`. New `.filter-chip` / `.filter-swatch` styles; the existing session-button tooltip rule was generalized to cover both.
