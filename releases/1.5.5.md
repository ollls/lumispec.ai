# LLM Workbench v1.5.5

## Overview

The app now knows which Python it runs and tells the model how to add a package there; a single
answer can no longer run to the context wall; conversations started from a template get a real
title; and the template review no longer calls a clock "static".

Five commits on `dev` since v1.5.4 (2026-11-07), 18 files, +447 / −37.

---

## 🐍 Python environment, detected

`PYTHON_VENV` is optional and may point at any directory with `bin/python` — venv, virtualenv, uv,
pyenv or conda. `services/pythonEnv.js` probes it once (interpreter, version, pip present, uv and
conda markers) and derives the install command that works there: `uv pip install --python …`,
`python -m pip install`, `conda install -p …`, or `python3 -m pip install --user` when unset.

- `run_python`, `source_run` and `source_test` run with the venv activated (`PATH` + `VIRTUAL_ENV`,
  what `source activate` does), however the server was started. Unset leaves the environment alone.
- The Code Execution prompt names the interpreter and the install command. A `ModuleNotFoundError`
  in `run_python` gets a `hint` with that command (`cv2` → opencv-python, `PIL` → pillow, …).
- `source_run` refuses a `pip install` only when the venv has no pip of its own (the uv case, where
  `pip` on PATH is the system one) and answers with the right command. That is how `reportlab` went
  into the user site with `--break-system-packages` on 2026-11-07 while the venv never saw it.

## ⏱ Per-answer token cap

`LLAMA_MAX_COMPLETION_TOKENS` (default 24576; 0 disables) is sent as `max_tokens` on every
streaming completion. One round had generated ~30K tokens over 3.5 minutes before its first tool
call. A round that hits the cap is labelled "cut off at the per-answer limit" with the count, not
blamed on the context.

## 🏷 Titles and the review

- A conversation is titled from the message as typed; `[template: CHPY]` becomes "Template: CHPY"
  instead of the first sentence of the expanded instruction block.
- The template audit no longer calls a clock-driven template static (`new Date()`, `setInterval`,
  `requestAnimationFrame` count as dynamic), and the review rules forbid adding a data source the
  template never had. Beautiful Watch is restored with only the resize message it was missing.

## ✅ Validation

`npm test`: 108/108 (98 at v1.5.4 + 10). No extension change, no reload. **Upgrade:** `git pull` →
restart. Optional: `LLAMA_MAX_COMPLETION_TOKENS` in `.env` if 24576 is not the cap you want.
