# LLM Workbench: lumispec.ai, v1.5.2

One-fix patch on v1.5.1. **A task-pipeline step whose incoming context was clipped was told so only by a tail marker it ignored.** A subtask group's outputs are merged before the 32K-char hand-off cap applies, so a wide fan-out loses its last siblings whole: on 2026-11-03 thirteen fetched news fronts merged to 60K chars, the dashboard step received 7½ outlets and presented 8 as the whole set. The clip now logs a server warning naming the section it cut and every section it dropped, streams a `context_truncated` event that draws a persistent amber line under the step, and opens the model's previous-output block with a `> ⚠` notice telling it to say what is missing. The cap itself is unchanged and documented in `.env.example`. Also ships the **World NEWS** dashboard template from the README screenshot.

No `.env` change, no extension change, no reload. **Upgrade:** `git pull` → restart, hard-refresh the UI once.
