# LLM Workbench: lumispec.ai, v1.6.5.b

Corrections to the experimental Amazon Cart plugin. No extension reload needed.

- **Product links** — every title in a search or cart table links to the product page on Amazon. Before, only the item number was shown.
- **Links open in a new tab** — any link to another site in an answer; before, it replaced the app and stopped running turns.
- **Pictures in tables stay thumbnail-sized** (140 px at most).
- **A refusal from Amazon stops the searches already waiting**, not only the ones asked for afterwards.

`npm test`: 254/254; all four search engines read correctly on 2026-11-27. The picture bound and the new-tab click were not checked in a browser. The model can still leave pictures or links out of a table it writes itself, and with the plugin off (it is after every restart) nothing keeps the model from loading Amazon pages another way. No `.env` change. **Upgrade:** `git pull` → `npm run css:build` → restart → hard-reload the page → turn Amazon Cart on again.
