# LLM Workbench: lumispec.ai, v1.1.0

Local-first AI assistant with dual LLM backend (llama.cpp + Claude), 20-round tool execution, and comprehensive integrations. This release hardens the knowledge layer against documentation hallucination and refreshes the recommended local model.

**New in v1.1:**

- 📝 **Cite mode** — code-citation discipline that guards against documentation hallucination. Architectural claims in `.md` writes and wiki entries require `(file:line)` citations: the diff preview soft-warns on uncited claims, and `wiki_index` hard-refuses entries whose citations don't resolve on disk. On by default.
- 🧠 **Refreshed model guidance** — Qwen3.6-27B (dense) is now the recommended backend, with a documented Gemma alternative. Always launch with `--jinja` (never `--chat-template gemma`, which leaks control tokens and flips output language on newer Gemma models).
- 🏨 **Hotel search fix** — name/city searches now require `countryCode`, preventing LiteAPI from silently returning empty result sets.

**Also includes (from v1.0):**

- 🛠️ **Source Tools** — 8-tool family for self-aware code management (edit, read, grep, git, test, run) with color-coded diff previews and blocked destructive git ops
- 🌐 **Web Research** — 3 engines (Tavily, Keiro, DuckDuckGo) + 3 fetch modes (Regular, Stealth, Browser)
- 🎯 **TaskMaster + Task Pipeline** — context isolation for low-memory local LLMs (bounded per-step context)
- 📊 **E*TRADE** — full brokerage with options Greeks, real-time quotes, portfolio tracking; the LLM never does math itself — Python does
- 📈 **Applets** — inline visualizations (SVG, Chart.js, HTML) rendered in the chat bubble
- 🔧 **Plugin System** — modular tool groups with dependency graph, hot reload, cycle detection
- 📚 **Wiki Plugin** — two-tier RAG with compressed documentation indexing

**Install**: `git clone` → `npm install` → `npm run css:build` → `npm start`

**Run a model** (separate terminal):
```bash
./llama.cpp/build/bin/llama-server \
  -hf unsloth/Qwen3.6-27B-GGUF:Q6_K_XL \
  --n-gpu-layers 99 --ctx-size 76000 --flash-attn on --jinja \
  --host 0.0.0.0 --port 8080
```
