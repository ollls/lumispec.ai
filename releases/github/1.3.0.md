# LLM Workbench: lumispec.ai, v1.3.0

Local-first AI assistant for llama.cpp (and optionally Claude). This release is about staying reliable through long tool runs on a local model: the tool loop now sees the context wall coming, the prompt prefix is byte-stable so the KV cache survives across turns, and a new **Retain** toggle keeps the model's own reasoning in context.

**New in v1.3:**

- 🧮 **Token-bounded tool loops** — both loops measure the real prompt via `/tokenize` every round and wind down at 80% of the live slot's `n_ctx`, trimming old tool results and forcing a final answer. Blank bubbles from `finish_reason: "length"` are gone: truncated answers are marked, empty ones keep their tool results and reasoning, and an empty pipeline step halts the run instead of poisoning the next step.
- ⚡ **Stable prompt prefix** — the clock moved out of the system prompt onto the user message, re-derived from a stored `sentAt` on replay. Measured: ~6,400 processed prompt tokens per turn → ~80.
- 🧠 **Retain toggle** — sends `reasoning_content` back on every assistant message so the model sees its prior thinking in later rounds and turns. Counted by the context budget, stripped for the Claude backend, off by default.
- 🌐 **Web research hardened** — `puppeteer-core` 25, one shared Chrome that closes when idle, hard protocol timeouts, and a new `auto` fetch mode (stealth → browser only when blocked). DuckDuckGo is no longer dropped in `regular` mode and Keiro results are no longer silently discarded by a wrong response-shape parse.
- 🎯 **Pipeline output folds** — completed steps collapse, the last stays open, the live step scrolls in its own box, and subtasks stream in chronological order.
- 🔍 **Route decision logging** (`ROUTE_LOG=1`) — JSONL record per routing decision plus two analysis scripts. The finance fabrication guard now requires an actual chain row and no tool run this turn, ending false positives; `bare-json` and `malformed-tag` repairs are disjoint and say what they mean.
- 🛠️ **`source_read` grep fixed** — path globs work (`src/tools/*.js`), `node_modules` is excluded, 4 MB chunked buffers with partial results on overflow, no shell interpolation of patterns.
- 📚 **Model guide** — the launch script that is actually proven stable, with an `Xid 8` stability note, plus a third script for the Qwen3.8-27B Defiance variant.

**Upgrade:** `git pull` → `npm install` (puppeteer-core major bump) → restart. Three new optional `.env` variables: `LLAMA_MAX_CONTEXT`, `MAX_PREV_RESULT_CHARS`, `ROUTE_LOG`.

**Run a model** (separate terminal — see README "Choosing & running your model" for the full flag table):
```bash
./llama.cpp/build/bin/llama-server \
  -hf unsloth/Qwen3.8-27B-GGUF:Q6_K_XL \
  --n-gpu-layers 99 --ctx-size 64000 --flash-attn on \
  --cache-type-k q8_0 --cache-type-v q8_0 \
  --spec-default --spec-type draft-mtp \
  --temp 1.0 --top-p 0.95 --top-k 20 --min-p 0.0 \
  --jinja --port 8080
```
