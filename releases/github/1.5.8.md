# LLM Workbench: lumispec.ai, v1.5.8

The model can now troubleshoot its own applets. It could never see them — in later turns an applet reaches the model as `[Applet: html visualization]`, and what breaks inside one happens in the browser — so a "fix" was a rewrite from memory.

- **Troubleshoot button** under every applet — fills the prompt with your problem line, a browser report and the call that reads the applet's code back. Nothing is sent until you submit.
- **Browser report** — uncaught errors, rejected promises, `console.error`, failed loads and non-OK fetches from inside the applet, plus rendered height and visible text.
- **`conversation_read` tool** — returns the exact applet source, tool results or reasoning of an earlier answer in the same conversation.
- **An applet is never clipped** — the frame is sized to the larger of what the applet asks for and what it renders.

`npm test`: 127/127. No `.env` change, no extension change. **Upgrade:** `git pull` → restart → hard-reload the page.
