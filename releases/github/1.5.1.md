# LLM Workbench: lumispec.ai, v1.5.1

One-fix patch on v1.5.0. **Bing searches through Browser Search answered only the first word of every query** — "What is AI" for "AI stocks sell off news…", driver downloads for "Intel quarterly earnings…". Bing received the full query but, with `count=10` on the URL, served a stripped page with entity results for the leading term. The parameter is gone; Bing now returns ten correct results per query (verified live, twice). DuckDuckGo was never affected.

No `.env` change, no extension change, no reload. **Upgrade:** `git pull` → restart.
