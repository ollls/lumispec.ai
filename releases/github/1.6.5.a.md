# LLM Workbench: lumispec.ai, v1.6.5.a

Two additions after v1.6.5. **Reload the Browser Search extension** (0.8.0 → 0.9.0) to use Amazon Cart.

- **Print** — a Print button on every answer and under every applet. An answer prints as a clean black-on-white document (tables with borders, header row on every page), without the chat around it. `/print.html?file=NAME` prints a saved markdown file. Before this, a print button written by the model did nothing: the browser blocks printing inside applets without an error.
- **Amazon Cart** *(experimental, off by default)* — the assistant searches Amazon, shows products with pictures, reads your cart and adds items to it in your own Chrome. Every add asks for your approval, and it never buys. It is off again after every restart of the app.

`npm test`: 253/253; all four search engines read correctly on 2026-11-26. Print was checked in headless Chrome, not in a visible browser's dialog. Amazon refused automated access three times during development, and adding to the cart has not been run end to end against the live site. The system prompt gains a short Printing section. No `.env` change. **Upgrade:** `git pull` → restart → reload the extension at `chrome://extensions` → hard-reload the page.
