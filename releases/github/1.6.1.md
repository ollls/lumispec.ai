# LLM Workbench: lumispec.ai, v1.6.1

Lumispec can now keep facts across conversations. Ask it to remember something and, after your approval, the new **Memories** plugin carries that fact into every later chat.

- **Memories plugin** (off by default) — save, change and forget by asking; every save and forget waits for your approval, and Autorun does not skip it. No search step: each memory has one line in the assistant's instructions.
- **Colors and the card** — a memory can be tied to a session color on request; the card lists every memory with color chips, search and a two-click delete. One Markdown file per memory in `data/memory/`.
- **Slot layouts for llama-server** — one slot with a 112K window is now the recommended layout on a 32 GB card; the README explains the shared four-slot pool, the four-slot layout with a window each, and the measured cache reuse of each.
- **Route log records every tool-call patch** — with `ROUTE_LOG=1`, each round lists the silent repairs its tool calls needed and the measured window fill; `scripts/output-fixes.mjs` tabulates them.
- **Applets are not isolated from the app** — the README now says so; the fix is tracked in `TODO.md`.

`npm test`: 172/172. No `.env` change, no extension change. With Memories off the system prompt is identical to v1.6.0. **Upgrade:** `git pull` → restart → hard-reload the page.
