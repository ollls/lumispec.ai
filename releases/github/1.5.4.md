# LLM Workbench: lumispec.ai, v1.5.4

- **Templates are reviewed on save** by the LLM (audit → prompt → guarded replacement), with ⚡ to run it again.
- **Template author notes live apart from the HTML** (`tpl.notes`), shown to the model outside the code fence and never copied into the applet — a 1,761-char comment was being reproduced verbatim on every run until a one-character slip broke the script.
- **A review answer must parse.** Inline scripts are parsed before replacing the original; the review model broke the same regex literal twice in one day, and the guard kept the template the second time.
- Sidebar **title filter**, `/api/yahoo` proxy for applets, and a `$`-pattern fix in template expansion.

`npm test`: 98/98. No `.env` change, no extension change, no reload. **Upgrade:** `git pull` → restart.
