# LLM Workbench: lumispec.ai, v1.6.2

Lumispec can now tell you about the llama-server it talks to. A chip icon in the top bar opens the new **Llama Dashboard**.

- **Llama Dashboard** — the model and build that are running, the launch command as it is running, GPU memory split into llama-server and everything else, temperature and power.
- **Speed** — generation tokens per second, prompt reading speed, the share of the prompt served from cache and MTP draft acceptance, measured from every answer. The top bar shows each answer's tokens per second next to the timer.
- **Stability** — GPU errors (Xid) from the kernel log for the last 90 days, with an amber dot on the icon after a recent one.
- **Updates** — how many commits the llama.cpp checkout is behind upstream and which recent ones touch the server, CUDA or speculative decoding. It only reports; nothing is pulled or rebuilt.
- **Top bar** — timer and speed always shown, tool icon always shown, menus and the Context bar rearranged to use less space.

Nothing changes in how llama-server is started. With the server on another machine, the GPU, stability and process cards are left out and say why.

`npm test`: 184/184. One optional `.env` setting (`LLAMA_CPP_DIR`), no extension change, system prompt unchanged. **Upgrade:** `git pull` → restart → hard-reload the page.
