# LLM Workbench: lumispec.ai, v1.6.0

Lumispec can now read a book with you. Point the new **Books** plugin at a folder of Markdown or text files, a single file, or a PDF, open it, and the assistant answers from the book first and names the section each answer rests on.

- **Books plugin** (off by default) — add a book from the card or from chat; it is indexed in the background, one summary per section, and questions work before indexing finishes.
- **PDF books** — converted to Markdown in seconds (headings from the PDF outline, code fenced, running headers dropped), then indexed. The card reports "Step 1 of 2" and "Step 2 of 2". 690 pages converted in 1.4 s.
- **Book only** — while a book is open, every other tool is withheld and the assistant says "not in this book" instead of looking elsewhere.
- **Troubleshoot on any answer** — a red Troubleshoot on every answer has the model read back what its tools actually returned and correct the answer instead of rerunning the prompt. Works on good runs too ("verify these numbers").

`npm test`: 153/153. No `.env` change, no extension change. PDF books need PyMuPDF in the Python environment; the card shows the install command. **Upgrade:** `git pull` → restart → hard-reload the page.
