# LLM Workbench: lumispec.ai, v1.5.6

One tool result can no longer sink a turn. A `tree` of a 7,000-file repository put 428K chars (~110K tokens) into the prompt; the next request was 131K tokens against a 64K slot and llama-server answered 400.

- **`tree` summarized over 300 files** — top-level layout with counts, first 300 paths, optional `path` to list one subdirectory. The same tree is 14.5K chars.
- **Executor ceiling** — every tool result is capped at 50,000 chars with an envelope naming the original size and carrying the head.
- **The wind-down fits the prompt** — if trimming old results is not enough, every result is cut to 4000 → 1500 → 400 chars until the prompt fits, in both loops.

`npm test`: 112/112. No `.env` change, no reload. **Upgrade:** `git pull` → restart.
