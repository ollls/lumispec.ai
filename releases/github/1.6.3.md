# LLM Workbench: lumispec.ai, v1.6.3

Two small changes after v1.6.2.

- **Filter conversations by pinned** — a pin button at the end of the sidebar's title-filter row steps through all, pinned only and not pinned. It combines with the color chips and the title box and is kept across reloads.
- **Llama Dashboard: no empty cards** — a card with nothing to show is left out. Off Linux nothing on the machine is probed and the dashboard shows the server, model and speed cards; the GPU, stability and launch-command cards appear on Linux with an NVIDIA card and llama-server on the same machine. One line under the cards says so when some are missing.
- **Linux with an NVIDIA card is recommended** for the dashboard; the README says so.

`npm test`: 184/184. No `.env` change, no extension change, system prompt unchanged. The macOS and Windows behaviour was simulated, not run on those systems. **Upgrade:** `git pull` → restart → hard-reload the page.
