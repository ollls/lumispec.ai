# LLM Workbench: lumispec.ai, v1.5.5

- **Python environment detected.** `PYTHON_VENV` may be a venv, uv, pyenv or conda directory, or unset. The app probes it once, activates it for `run_python` and `source_run`, tells the model the install command that works there, and adds that command to any `ModuleNotFoundError`. A `pip install` that would hit the system Python instead of the venv is refused with the right command.
- **Per-answer token cap.** `LLAMA_MAX_COMPLETION_TOKENS` (default 24576) bounds every streaming completion; a runaway answer ends in minutes, not at the context wall, and is labelled as such.
- **Template runs get a title** ("Template: CHPY"), and the template review no longer treats a clock as static or invents a data source.

`npm test`: 108/108. No extension change, no reload. **Upgrade:** `git pull` → restart.
