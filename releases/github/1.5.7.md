# LLM Workbench: lumispec.ai, v1.5.7

A running answer survives leaving its conversation. Switching conversations used to abort the turn in flight and lose its answer, tool results and reasoning; starting a new chat let the old stream wipe the new one's bubble.

- **Conversations keep running** — switch away or start a new chat and the turn continues; come back to the live bubble. Send, Stop and the timer follow the conversation on screen, and a pulsing dot in the sidebar marks the ones working. A page reload still stops running turns.
- **Stopped turns keep their work** — a stopped turn is stored with its reasoning and tool results instead of an empty message; a stopped pipeline keeps its completed tasks.
- **Applets fit the chat area** — charts, SVGs and images are capped to the visible chat height. A Chart.js canvas used to render 1,763px tall in a 625px area.
- **Prompt box keeps its dragged height** — typing no longer pins the textarea to 200px in a taller pane.

`npm test`: 119/119. No `.env` change, no extension change. **Upgrade:** `git pull` → restart → hard-reload the page.
