# LLM Workbench: lumispec.ai, v1.4.0

Local-first AI assistant for llama.cpp (and optionally Claude). This release adds a second way to reach the web: **Browser Search**, a small Chrome extension that loads search results and articles in a hidden tab of *your own* browser and hands the rendered page back to the assistant. Real Chrome, real cookies, real TLS fingerprint — Google, Bing, Brave and bot-walled sites such as Reuters answer the way they answer a person.

> ⚠️ **Requires a Chrome extension you install yourself** (Chrome, Edge, Brave — any Chromium browser; loaded unpacked, no store listing). Step-by-step install, verify, update and remove guide: [`extension/README.md`](extension/README.md). Browser Search is optional and off by default; without the extension every call falls back to the regular HTTP search and says so.

**New in v1.4:**

- 🌐 **Browser Search plugin** — `web_search` and `web_fetch` through a hidden tab of your Chrome. Pick one engine (DuckDuckGo, Brave, Bing, Google) on the Plugins card. Bot-challenge walls are outwaited in the same tab (Reuters clears in ~8 s, then loads in ~1 s). Every fallback to HTTP is disclosed in the tool result — nothing falls back silently.
- 🧩 **Engine-agnostic extension** — the extension only loads URLs and returns rendered HTML. Engine URLs, CAPTCHA detection and parsers live server-side in `plugin-browser.js`, so adding or fixing an engine never requires reloading the extension; the card flags an outdated one.
- 🔌 **Plugin supersession** — a plugin can `supersedes: ['web']`: while it is on, the replaced group is paused and its slider grayed at its saved position; turning it off restores the group exactly. Plus live card status lines (`cardStatus()`), enable-time warnings (`enableWarning()`), and per-plugin panel controls (`configUi()`).
- 🟢 **Browser status dot** — green while the extension is connected; the card says connected + version, disconnected + last seen, or points you to the install guide.

**Upgrade:** `git pull` → `npm install` (new `ws` dependency) → restart → load `extension/` in Chrome per [`extension/README.md`](extension/README.md) → enable **Browser Search** in Plugins. Two new optional `.env` variables: `BROWSER_SEARCH_TOKEN`, `BROWSER_SEARCH_TIMEOUT_MS`.

**Run a model** (separate terminal — see README "Choosing & running your model" for the full flag table):
```bash
./llama.cpp/build/bin/llama-server \
  -hf unsloth/Qwen3.8-27B-GGUF:Q6_K_XL \
  --n-gpu-layers 99 --ctx-size 64000 --flash-attn on \
  --cache-type-k q8_0 --cache-type-v q8_0 \
  --spec-default --spec-type draft-mtp \
  --temp 1.0 --top-p 0.95 --top-k 20 --min-p 0.0 \
  --jinja --port 8080
```
