# LLM Workbench: lumispec.ai, v1.4.1

Local-first AI assistant for llama.cpp (and optionally Claude). A small, single-feature release on top of v1.4.0: **Obsidian export**. Any conversation can now be saved into your Obsidian vault as a Markdown note with one click — properties, one heading per turn, tool calls folded into callouts, charts and data files copied alongside as attachments.

> 📓 **Manual, one-way, nothing deleted.** A note is written only when you click **Save to Obsidian** (or ask the model to). Pinning, new messages, title edits and compacts never touch the vault; nothing in the note links back to the app; the exporter never removes a file from the vault. Off by default. Design notes: [`docs/OBSIDIAN.md`](docs/OBSIDIAN.md).

**New in v1.4.1:**

- 📓 **Obsidian Export plugin** — turn it on in **Plugins** and a vault icon appears next to the pin on every conversation in the sidebar. One click writes `<Folder>/<session colour>/<slug>-<id8>.md`: YAML properties (title, id, created/updated, session colour, model, message and token counts, tools used, `lumispec/<colour>` tag), `## 🧑 / 🤖` headings per turn, tool calls as folded callouts (results trimmed to 1,500 chars, auto-saved CSVs linked), reasoning as a folded callout when enabled, task-pipeline runs as structured steps and subtasks. Saving again replaces the note with the conversation as it stands; a title or colour change renames it instead of duplicating it.
- 🗂️ **Vault discovery** — the card reads Obsidian's own registry (native, Flatpak and Snap installs) and writes into the vault currently open in Obsidian, else the most recently used; pick another from the dropdown, set the folder inside the vault (default `Lumispec`), and choose whether tool results (on) and reasoning (off) go into the note. No Obsidian on this machine? `OBSIDIAN_VAULT=/path/to/any/folder` in `.env` and the exporter writes plain Markdown there. With no vault anywhere the card says so and nothing is written.
- 📎 **Attachments and applets** — user images and `/files/<name>` data files referenced in the text are copied into the vault's attachment folder (honouring `.obsidian/app.json`) with links rewritten to `[[name]]`; applets are cut out into `.html` sidecars and linked. Writes are atomic (`.tmp` + rename), path-guarded to the vault root, and idempotent.
- 🧩 **Plugin cards gained generic fields** — `configUi()` can return `fields` (select / text / boolean) and the panel renders them under the slider; the server accepts only keys the plugin declares in its `defaults`, coerced to the declared type. Obsidian is the first consumer.
- 🩹 **Claude backend fix** — the default model is now `claude-sonnet-5-5`; the retired `claude-sonnet-4-20250514` made every request fail with a model-not-found error when `CLAUDE_MODEL` was unset.
- ✅ **`npm test`** — new `node --test` suite; `test/obsidian.test.js` covers the renderer, vault registry parsing and an end-to-end export into a temp vault (13 tests).

**Upgrade:** `git pull` → restart → **Plugins** → switch on **Obsidian Export** → pick the vault and folder on the card → hover a conversation in the sidebar and click the vault icon. No new dependencies. One new optional `.env` variable: `OBSIDIAN_VAULT`.

**Run a model** (separate terminal — see README "Choosing & running your model" for the full flag table):
```bash
./llama.cpp/build/bin/llama-server \
  -hf unsloth/Qwen3.8-27B-GGUF:Q6_K_XL \
  --n-gpu-layers 99 --ctx-size 64000 --flash-attn on \
  --cache-type-k q8_0 --cache-type-v q8_0 \
  --spec-default --spec-type draft-mtp \
  --temp 1.0 --top-p 0.95 --top-k 20 --min-p 0.0 \
  --jinja --port 8080
```
