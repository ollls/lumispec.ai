# LLM Workbench: lumispec.ai, v1.6.5

One fix after v1.6.4. **The Browser Search extension must be reloaded** (0.7.0 → 0.8.0).

- **Brave search works again** — since 2026-11-22 Brave hides the address of every result behind an encrypted redirect link, and every Brave search fell back to HTTP search. The extension now follows those links inside the results page, reads where each one leads and cancels it, so the result sites are never contacted. No new extension permission.
- **Clearer failures** — a Brave search that finds nothing says whether the extension is too old or the links could not be resolved.
- **Digital Watch templates** — a Digital Watch 2 template, and the first one no longer stops between 12:00 and 12:59.

`npm test`: 192/192. Eleven live Brave searches on 2026-11-23, all answered by Brave in about 3 s each; behaviour under many searches in a row is not tested. No `.env` change, system prompt unchanged. **Upgrade:** `git pull` → restart → reload the extension at `chrome://extensions` → hard-reload the page.
