# LLM Workbench v1.4.2 Release Notes

This fix release focuses exclusively on improving what `web_fetch` hands to the model, addressing defects where rendered pages arrived as empty, login screens, or incomplete summaries. It introduces generic index page detection to preserve headlines on homepages, strips dead markup like `<template>` and inline CSS before size caps, and implements a settle loop for progressive web apps. The Browser Search extension is updated to v0.5.0, requiring a reload, with new handling for iframe CAPTCHAs and login walls. Additionally, the release fixes a tool-call parser issue for Qwen3.8 shapes and makes applet HTML rendering tolerant of truncated closing tags.

## Key topics
- Web fetch improvements — Removes `<template>` blocks, detects index pages (≥20% headline link text), and makes the 4,000-char cap configurable.
- Browser Search extension v0.5.0 — Strips scripts/styles before capping, uses a 0.6s settle loop, prevents HTTP fallback for rendered pages, and detects iframe CAPTCHAs.
- Tool-call parser repairs — Fixes dropped quotes and key names for Qwen3.8, and bounds repair rounds to 3 to prevent infinite loops.
- Applet rendering fix — Accepts `</applet>` or end-of-text as terminators to handle models dropping the final `>` token.
- Plugin system updates — Adds `type: 'number'` fields and cross-group value targeting for the fetch cap setting.
- Validation and testing — 34 tests added, live validation on NYT, Reuters, and Gmail, and offline testing on 13 saved page copies.
