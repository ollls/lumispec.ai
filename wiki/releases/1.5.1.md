# LLM Workbench v1.5.1

This document details a one-fix patch for LLM Workbench v1.5.1, addressing a bug where Bing searches via Browser Search returned results for only the first word of the query. The issue was traced to the `count=10` parameter in the Bing engine URL, which caused the service to serve stripped pages with entity results for the leading term rather than the full query. The fix removes `count=10` from the URL, leaving only `q` and `setlang=en`, based on measurements showing this configuration yields 10 correct organic results. The release consists of four commits on the `dev` branch since v1.5.0, affecting 5 files with +80 and −3 lines of code. Validation confirmed the fix works for specific financial queries and `npm test` passed 50/50 without requiring changes to `.env` or the browser extension.

## Key topics
- Bing search bug — Full queries were reduced to first-word entity results due to URL parameters.
- URL parameter fix — `count=10` was removed from the Bing engine URL to restore correct search results.
- Release scope — Four commits, 5 files changed, +80/−3 lines, no changes to `.env` or extension.
- Validation results — Live tests confirmed correct results for specific queries; `npm test` passed 50/50.
