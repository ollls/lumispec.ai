# LLM Workbench v1.5.5 Release Notes

This release introduces automatic Python environment detection via `services/pythonEnv.js`, which probes `PYTHON_VENV` to derive correct install commands for venv, uv, conda, or system Python. It implements a per-answer token cap using `LLAMA_MAX_COMPLETION_TOKENS` (default 24576) to prevent single responses from hitting context limits, labeling capped rounds distinctly. Conversations started from templates now receive titles derived from the input message rather than expanded instruction blocks. The template audit logic was updated to recognize clock-driven functions like `new Date()` and `setInterval` as dynamic, and the "Beautiful Watch" template was restored. Validation shows 108/108 tests passing, with no extension changes required for upgrade.

## Key topics
- Python environment detection — Probes `PYTHON_VENV` for interpreter, pip, uv, and conda markers to set `PATH` and `VIRTUAL_ENV` for execution.
- Install command derivation — Generates specific commands like `uv pip install` or `conda install -p` based on detected environment markers.
- Per-answer token cap — Enforces `LLAMA_MAX_COMPLETION_TOKENS` (default 24576) on streaming completions to limit single response length.
- Template title generation — Titles conversations from the typed message (e.g., "Template: CHPY") instead of the first sentence of expanded instructions.
- Template audit updates — Recognizes `new Date()`, `setInterval`, and `requestAnimationFrame` as dynamic, preventing false "static" labels.
- Validation metrics — 108/108 tests passed (10 new tests added since v1.5.4).
