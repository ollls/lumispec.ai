# LLM Workbench v1.5.2

This release is a one-fix patch addressing silent context clipping in task pipelines, where previous step outputs exceeding `MAX_PREV_RESULT_CHARS` (32,000 default) were truncated without clear notification. The fix introduces explicit truncation signals across server logs, SSE streams, the chat UI, and the model's prompt, ensuring that lost sections are named and the model is instructed not to present partial data as complete. It also adds the "World NEWS" HTML template to `data/templates.json` and updates documentation in `docs/TASKMASTER.md` and `CLAUDE.md`. The update includes 11 files with +272/−21 lines of code and passes 55/55 tests.

## Key topics
- Context truncation fix — Replaces silent tail markers with explicit head-cut notifications in logs, SSE, UI, and model prompts.
- `truncatePrevResult()` — New pure function in `src/services/pipelineContext.js` that calculates dropped sections and generates truncation notices.
- World NEWS template — New HTML template in `data/templates.json` for an eight-outlet news dashboard, insertable via `[template: World NEWS]`.
- UI feedback — Persistent amber line in the chat UI stored on the step's `taskRun` entry as `contextTruncated`.
- Model prompt update — Previous output blocks now open with a warning instructing the model to state which sections were missing.
- Documentation updates — `docs/TASKMASTER.md` and `CLAUDE.md` updated to reflect head-cut behavior and new signals.
