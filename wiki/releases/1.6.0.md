# LLM Workbench v1.6.0 Release Notes

This release introduces the **Books** plugin, which indexes local Markdown, text, or PDF files into a searchable library that the assistant prioritizes for answers, and the **Troubleshoot** feature, which allows the model to read back tool results via `conversation_read` to correct previous answers without rerunning prompts. The Books plugin supports background indexing with a keyword-based search that works before indexing completes, handles long files by splitting them into sections, and includes a "Book only" mode that restricts the assistant to the open book. PDF support requires a two-step process: conversion to Markdown using `scripts/pdf_to_md.py` (PyMuPDF) followed by standard indexing. The release also adds optional plugin interface methods `exclusive()` and `configChanged()`, and includes fixes for applet history placeholders and `conversation_read` behavior.

## Key topics
- **Books plugin** — Indexes folders, single files, or PDFs; answers from the open book first with section citations; supports "Book only" mode to withhold other tools.
- **PDF conversion** — Uses `scripts/pdf_to_md.py` (PyMuPDF) to convert PDFs to Markdown, preserving headings and code blocks; reports progress and errors on the card.
- **Troubleshoot feature** — Adds a red button to every answer that fills a prompt with tool evidence via `conversation_read` to generate a corrected answer; includes a turn report of tool failures and truncations.
- **Plugin interface additions** — New optional methods `exclusive()` for tool restriction and `configChanged()` for card field validation; frontmatter helpers moved to `src/services/frontmatter.js`.
- **Validation and testing** — 153/153 tests passing, including 26 new tests for Books and Troubleshoot; validated with local Qwen3.8-27B on a 690-page PDF and an 84-section folder.
