# LLM Workbench v1.5.7 Release Notes

This release introduces concurrent conversation support, allowing turns to continue running when the user switches chats or starts new conversations, with controls and approvals scoped to the visible conversation. It fixes an issue where stopped turns left empty assistant messages in history by storing placeholder text with preserved reasoning and tool results. The update includes `applet-fit.js` to constrain Chart.js and SVG dimensions to the visible chat area (80% height, clamped 240–1200px) and prevents the prompt box from resetting to 200px when the pane has a user-set height. Six commits were made since v1.5.6, affecting 13 files with +716 / −113 lines, and validation passed 119/119 tests.

## Key topics
- Concurrent conversations — Turns persist across navigation; sidebar shows pulsing dots for active chats; page reload stops all turns.
- Stopped turn persistence — Stopped chats store `[Stopped before an answer was written.]` with reasoning/tool results; pipelines record stopped task status.
- Applet fitting — `applet-fit.js` caps chart/image height based on visible chat area; Chart.js plugin wraps oversized charts in fixed-height boxes.
- Prompt box height — Auto-sizing respects user-dragged pane height, preventing reset to 200px on first keystroke.
- Validation & Upgrade — 119/119 tests passed; upgrade via `git pull`, restart, and hard-reload; no `.env` or extension changes.
