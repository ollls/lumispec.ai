# LLM Workbench v1.5.3 Release Notes

This release introduces configurable research budgets, template-specific source exemptions, and enhanced tool parsing for the Claude backend. The "3 searches, 3 fetches" limit is now a card setting with config keys `web.maxSearchesPerQuestion` and `web.maxFetchesPerQuestion`, defaulting to 3 with a range of 0–10. Templates that explicitly name data sources are exempt from these budgets, requiring the model to fetch every listed source. The Claude backend now parses native `<invoke>` syntax, discloses dropped tool calls when exceeding the 4-per-round cap, and prevents duplicate logging for tools that declare `logsItself: true`.

## Key topics
- Research budget settings — Configurable limits for web searches and fetches per question, replacing hardcoded prompt text.
- Template source exemption — Templates naming specific data sources bypass the standard budget to ensure all listed sources are fetched.
- Claude backend tool parsing — Support for native `<invoke>` syntax and type coercion, matching llama's parsing behavior.
- Tool call cap disclosure — Dropped calls due to the 4-per-round limit are explicitly listed in the results message to the model.
- Logging deduplication — Tools declaring `logsItself: true` skip the executor's generic log entry to prevent duplicates.
- Validation and testing — 15 new tests added for research limits, template expansion, and invoke parsing, bringing the total to 70/70.
