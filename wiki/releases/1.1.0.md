# LLM Workbench v1.1.0 Release Notes

This release introduces Cite mode, a per-conversation feature designed to prevent documentation hallucination by enforcing code-citation discipline across three layers: system-prompt rules, diff-preview claim highlighting, and strict wiki-index validation. It also fixes a reliability issue in hotel search where missing `countryCode` parameters caused silent empty results and updates the default model to Qwen3.6-27B (dense). The release is purely additive, with all code paths verified at runtime, and includes new documentation on knowledge hardening and model launch scripts.

## Key topics
- Cite mode — Per-conversation toggle (on by default) that enforces `(file:line)` citations for architectural claims using a refuse-vs-warn asymmetry.
- Wiki index strict mode — Hard refusal of wiki entries with broken citations, reduced sampling temperature (0.2 → 0.1), and `cite_mode: true` frontmatter stamping.
- Hotel search fix — Prompt guidance updated to require `countryCode` for name/city searches to prevent silent empty results from LiteAPI.
- Model updates — Default model changed to Qwen3.6-27B (dense); README includes validated launch scripts for Qwen and Gemma with `--jinja` flag warnings.
- Validation — Runtime checks confirm citation validation logic, diff line tracking, and prompt injection behavior across 7 changed JavaScript files.
