# LLM Workbench v1.5.4 Release Notes

This release introduces background LLM reviews for templates upon saving, separating author notes from HTML content to prevent verbatim reproduction and syntax errors. A parse guard using `vm.Script` rejects review answers that contain invalid JavaScript, ensuring code integrity. The update includes a case-insensitive sidebar title filter and a GET-only `/api/yahoo` proxy for Yahoo Finance chart endpoints to support applet iframes. Six commits across 18 files resulted in +1,361 / −88 lines of code, with test coverage increasing to 98/98.

## Key topics
- LLM review on save — Background deterministic audit and model review of raw HTML with a guard preventing replacement by unparseable code.
- Author notes migration — Leading HTML comments moved to `tpl.notes` to serve as context without being copied into applets.
- Parse guard — Uses `vm.Script` to validate inline scripts in review answers, rejecting those that fail to parse.
- Sidebar title filter — Case-insensitive substring filter for conversation titles that composes with color chips.
- `/api/yahoo` proxy — GET-only endpoint whitelisting symbol, range, and interval parameters for Yahoo Finance chart data.
- Validation and upgrade — 98/98 tests passing; upgrade via `git pull` and restart, with automatic migration of existing templates.
