# LLM Workbench v1.4.1 Release Notes

This release introduces a single-feature addition: Obsidian export, allowing conversations to be saved as Markdown notes in an Obsidian vault with frontmatter, structured headings, and attached files. The export is manual, one-way, and non-destructive, preserving notes even if conversations are deleted or renamed. The plugin system was extended to support generic card fields (select, text, boolean) for configuration, and the conversation store now persists session colors and hidden session-init prompts. Additionally, the Claude backend default model was updated to `claude-sonnet-5-5` to replace a retired model ID, and a new `npm test` suite was added with 13 tests covering the Obsidian exporter.

## Key topics
- Obsidian export — Manual, one-way export of conversations to Markdown notes with frontmatter, tool callouts, and attachments.
- Plugin system fields — New `configUi()` support for generic form fields (select, text, boolean) with server-side validation.
- Conversation store updates — Persistence of `conv.session` color and `hidden` flag for session-init prompts; `conversationId` added to tool context.
- Claude backend fix — Default model changed to `claude-sonnet-5-5` because `claude-sonnet-4-20250514` was retired.
- Testing infrastructure — New `npm test` command using `node --test` with 13 tests for the Obsidian exporter.
- Configuration — `OBSIDIAN_VAULT` environment variable allows writing to a path without Obsidian installed; plugin settings stored in `data/plugins.json`.
